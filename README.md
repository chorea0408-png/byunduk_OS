## 실행 방법

그냥 `index.html`을 브라우저로 열면 됩니다. (더블클릭 또는 브라우저 창에 드래그)

- 별도 설치나 빌드가 필요 없습니다.
- 입력한 데이터는 브라우저의 localStorage에 저장됩니다.

## 외부 의존성

- **Tabler Icons** — 아이콘 웹폰트
- **Chart.js** — 차트

두 가지 모두 CDN으로 불러오므로 인터넷 연결이 필요합니다. 인터넷이 없으면 아이콘과 차트만 표시되지 않고, 나머지 기능은 정상적으로 동작합니다.

## 리팩토링 히스토리

이 프로젝트는 지금까지 다섯 차례 리팩토링을 거쳤습니다.

1. **1차**: 최초 통짜 HTML 파일(약 7,674줄)을 `index.html` / `css/` / `js/` 3개로 분리.
2. **2차**: 이후 CSS와 JS를 각각 기능별 파일로 세분화. 각 탭/기능이 자신만의 css·js 파일을 갖도록 정리했습니다. (`crm.js`도 이후 `crm-core.js` / `crm-detail.js` / `crm-deals.js`로 추가 분할)
3. **3차 (디자인 개편)**: Notion·Toss 스타일의 미니멀 디자인을 도입했습니다.
   - 색상/간격/모서리/그림자/타이포그래피를 `base.css`의 디자인 토큰 체계로 재정의
   - 버튼·카드·모달·탭·KPI 등 공통 컴포넌트를 노션·토스 스타일로 재정비
   - 화면 전반의 정보 밀도 개선 (여백/타이포 정리)
   - 홈 화면의 긴 목록에 더보기/접기 기능 추가
   - 다크/라이트 모드 수동 전환 버그 수정, 그리고 회귀 검증 과정에서 발견된 다크 모드 카드/배지 대비 문제(고정 라이트 틴트 배경에 테마 텍스트가 겹쳐 안 보이던 문제) 수정
4. **4차 (업무 로직 개선)**: 실사용자 편의성 관점에서 발견된 데이터/명명 불일치를 개선했습니다.
   - **월 매출 자동 계산**: 월 매출 계산을 청구서(실제 입금 확인) 기준으로 자동화했습니다. 연간목표·수익성 분석·지출 트래커가 각자 다른 값을 쓰던 것을 하나의 계산 결과로 통합해서 공유합니다. 청구서 데이터가 없는 과거 달은 기존 수동 입력값을 그대로 보존합니다.
   - **캐파시티 실측화**: 캐파시티(업무량) 계산을 실제 시간기록(`cl.timeLog`) 기준으로 변경했습니다. 시간기록이 없는 고객은 추정치로 자동 보완하며, 고객별로 "실측 기준"/"추정 기준" 여부를 표시합니다.
   - **탭 이름 정리**: '관계 티어' 탭을 실제 기능(뉴스레터/구독자 관리)에 맞게 '팬 등급 관리'로 이름을 변경했습니다.
5. **5차 (데이터 안전성 & 설치 지원, 현재 구조)**: 데이터 손실 위험을 줄이고, 앱처럼 설치해서 쓸 수 있도록 개선했습니다.
   - **백업 안전장치 강화**: 헤더에 마지막 백업일을 표시하고, 백업이 오래되면 홈 화면에 백업을 권유하는 배너를 노출합니다. 데이터 가져오기(import) 시에는 파일 형식을 검증하고 확인창을 거치며, 실행 전 자동으로 스냅샷을 생성해 실수로 인한 데이터 유실을 방지합니다.
   - **첫 사용자 온보딩**: 데이터가 없는 최초 실행 시 "빈 상태로 시작" / "샘플 데이터로 둘러보기" 중 선택할 수 있는 화면을 추가했습니다. 기존에 데이터를 보유한 사용자에게는 아무 영향이 없습니다.
   - **PWA 설치 지원**: `manifest.json` + 아이콘 + 최소 서비스워커(`sw.js`)를 추가해 브라우저에서 "앱으로 설치"할 수 있게 했습니다. 오프라인 지원은 이번 범위에 포함되지 않았습니다 — CDN(Tabler Icons, Chart.js) 의존성 때문에 별도 과제로 보류했습니다.

앞으로 새 기능을 추가할 때는 해당 기능의 css/js 파일에 추가하면 됩니다. `index.html`의 스크립트 로드 순서(`core.js` → `shared.js` → 기능별 파일들 → `init.js`)는 반드시 유지해야 합니다 — 순서를 바꾸면 오류가 날 수 있습니다.
